# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/7993bbe1-d8fb-49e9-90fb-812ab5b9a459

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app (AI requests use the shared Bold Studio Gemini proxy; this app does not need its own API key):
   `npm run dev`
